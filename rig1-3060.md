# Rig 1: RTX 3060 + i7-12700

- GPU: NVIDIA GeForce RTX 3060 12GB (compute 8.6)
- CPU: Intel i7-12700
- RAM: 128 GB DDR4-3200
- Host: Unraid
- First benchmarked: 2026-09-10
- Stock: [upstream llama.cpp](https://github.com/ggml-org/llama.cpp), v0.5.0-dev d834d44 since the 2026-09-26 llama-swap container rebuild (older stock rows measured on v0.4.0-dev 30b6a75). The moe-cache fork is build b11814-28d73c87c (since 2026-10-08).

- [Strata](https://github.com/Niko1221/Strata) runs on Rig 1 as a pack engine: `strata` 0.1.40.2 (with `strata-vision`), built from source for sm_86. Not a `llama-server` build - see [engine-notes/strata.md](engine-notes/strata.md); its rows are on the [Qwen3.8-Flash-Next](models/rig1-3060/qwen38-flash-next.md) page.
