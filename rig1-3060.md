# Rig 1: RTX 3060 + i7-12700

- GPU: NVIDIA GeForce RTX 3060 12GB (compute 8.6)
- CPU: Intel i7-12700
- RAM: 128 GB DDR4-3200
- Host: Unraid
- First benchmarked: 2026-09-10
- Stock: [upstream llama.cpp](https://github.com/ggml-org/llama.cpp), v0.5.0-dev d834d44 since the 2026-09-26 redeploy (older stock rows measured on v0.4.0-dev 30b6a75). The moe-cache fork is build `f3f31a788` (`0.6.0-dev`, build 11997) since 2026-10-20.
- ik-llama.cpp was additionally tested on Rig 1: build 1aaf710 (v1) of [ik_llama.cpp](https://github.com/ikawrakow/ik_llama.cpp) - results are kept in each model's page (e.g. [models/rig1-3060/qwen36-35b-a3b.md](models/rig1-3060/qwen36-35b-a3b.md)); older ik rows (measured before 2026-09-26) were on build 3bb386e.
- [Strata](https://github.com/Niko1221/Strata) runs on Rig 1 as a pack engine: `strata` 0.1.45 (with `strata-vision`), built from source for sm_86 from tag `v0.1.45` (`477ac13c`), with the upstream CUDA decode switches on and the vision encoder enabled (CPU, BF16 mmproj). Not a `llama-server` build - see [engine-notes/strata.md](engine-notes/strata.md); its rows are on the [Qwen3.8-Flash-Next](models/rig1-3060/qwen38-flash-next.md) page.
- The model pages reference the models root as `<models>/`.

All pages under [models/rig1-3060/](models/rig1-3060/) are Rig 1 results. Methodology: [methodology.md](methodology.md).
