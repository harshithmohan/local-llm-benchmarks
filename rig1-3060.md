# Rig 1: RTX 3060 + i7-12700

- GPU: NVIDIA GeForce RTX 3060 12GB (compute 8.6)
- CPU: Intel i7-12700
- RAM: 128 GB DDR4-3200
- Host: Unraid
- First benchmarked: 2026-09-10
- [gpu-unlock](https://github.com/Zagitta/gpu-unlock) runs on this rig too: loaded at boot since 2026-11-06 (fork plugin, `install nvidia` hook), so rows measured from that date are unlocked.
- Stock: [upstream llama.cpp](https://github.com/ggml-org/llama.cpp), v0.5.0-dev d834d44 since the 2026-09-26 redeploy (older stock rows measured on v0.4.0-dev 30b6a75). The moe-cache fork is build `f3f31a788` (`0.6.0-dev`, build 11997) since 2026-10-20.
- ik-llama.cpp was additionally tested on Rig 1: build 1aaf710 (v1) of [ik_llama.cpp](https://github.com/ikawrakow/ik_llama.cpp) - results are kept in each model's page (e.g. [models/rig1-3060/qwen36-35b-a3b.md](models/rig1-3060/qwen36-35b-a3b.md)); older ik rows (measured before 2026-09-26) were on build 3bb386e.
- [Strata](https://github.com/Niko1221/Strata) runs on Rig 1 as a pack engine: `strata` **0.2.10** (build `0.1.56`, with `strata-vision`), deployed from upstream's release tarballs for sm_86 on 2026-11-03, with the engine's own sm_86 switch table (we set `EXPDEC`, `QSA_SPLIT_ATTN`, `PREFILL_LEND_PCT`, `KEEP_EMPTY_TURNS`, `ROUTE_PRIOR` and `PF_SMALL`), the base entry on DFlash2 and the Swift entry on MTP, and the vision encoder enabled (CPU, BF16 mmproj). Not a `llama-server` build - see [engine-notes/strata.md](engine-notes/strata.md); its rows are on the [Qwen3.8-Flash-Next](models/rig1-3060/qwen38-flash-next.md) and [Swift-1.5-Qwen3.8-Flash-Next](models/rig1-3060/swift-qwen38-flash-next.md) pages.
- The model pages reference the models root as `<models>/`.

All pages under [models/rig1-3060/](models/rig1-3060/) are Rig 1 results. Methodology: [methodology.md](methodology.md).
