# Rig 2: RTX 3090 + Ryzen 7 5700X

- GPU: NVIDIA GeForce RTX 3090 24GB (compute 8.6)
- CPU: AMD Ryzen 7 5700X (8c/16t, tests used `--threads 8`)
- RAM: 32 GB DDR4-3200
- VRAM budget: 22 GB +- 250 MB for llama.cpp (desktop system, not headless)
- Stock binary: upstream llama-server (upstream 0.4.0-dev, build 10809, commit 5266f24da7)
- Codacus fork ([github.com/thecodacus/llama.cpp](https://github.com/thecodacus/llama.cpp)):
  built from a local checkout (b10818/27c54b4bb). Its
  `libggml-cuda.so` needs the CUDA 12 runtime; this machine has CUDA 13, so
  run fork binaries with a `LD_LIBRARY_PATH` pointing at staged CUDA 12
  libs (libcudart.so.12 + libcublas.so.12 + libcublasLt.so.12 from the local pip nvidia
  packages). A CUDA 13 rebuild would remove that step but does not change performance
  (bandwidth-bound, same kernels).
- Models live under a models root (referenced as `<models>/` in the configs below); profiles at `<models>/moe-cache-profiles/`
- Benchmark results: [models/rig2-3090/qwen36-35b-a3b.md](models/rig2-3090/qwen36-35b-a3b.md)
